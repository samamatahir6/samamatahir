Plugin WordPress · Gravity Forms para Wealthbox CRM

Cada contacto do Gravity Forms, direto para o Wealthbox

O Mappings for Wealthbox transforma cada submissão de formulário num contacto no Wealthbox no momento em que chega. Sem Zapier, sem exportar CSV, sem copiar e colar. Escolha um formulário, associe os campos e publique.

Porque o Criei

Os seus contactos chegam pelo site. O seu negócio vive no Wealthbox.

O Gravity Forms é ótimo a captar contactos, mas é no Wealthbox que os consultores trabalham de facto. Passar de um para o outro costuma exigir um serviço de automação pago ou copiar entradas à mão.

Criei o Mappings for Wealthbox para fechar essa lacuna dentro do WordPress. Escolha um formulário, associe os campos e cada novo contacto chega ao Wealthbox sozinho. O Pro acrescenta campos personalizados, atualização de contactos, registos de sincronização e formulários aninhados.

Como Funciona

Três passos, sem código

  1. 1

    Ligar

    Cole o seu token da API do Wealthbox em Wealthbox, Settings e clique em Test connection.

  2. 2

    Associar

    Escolha um formulário do Gravity Forms. Para cada campo, escolha o campo do Wealthbox numa lista com pesquisa.

  3. 3

    Publicar

    Cada nova submissão passa a criar o contacto no Wealthbox.

  4. 4

    Verificar (Pro)

    Quem volta é atualizado, não duplicado, e cada sincronização fica no registo.

Veja a Funcionar

Dentro do seu painel WordPress

Três ecrãs fazem o trabalho: o ecrã de associação, a correspondência de contactos e o registo de sincronização.

O Fluxo

Do botão enviar ao CRM em segundos

Tudo corre dentro do seu próprio site WordPress. Nenhum serviço externo fica pelo meio.

  1. Formulário enviado

    Um visitante preenche qualquer formulário do Gravity Forms.

  2. Associação aplicada

    Cada campo vai para o seu campo no Wealthbox.

  3. Contacto reconhecido

    O Pro verifica o email ou telefone de quem volta.

  4. Guardado no Wealthbox

    Criado de novo ou atualizado.

  5. Registado

    O Pro regista o resultado para poder confirmar.

Perguntas Frequentes

Respostas diretas

Preciso do Zapier ou de outra ferramenta de automação?

Não. O plugin comunica diretamente com a API do Wealthbox a partir do seu site WordPress.

Atualiza pessoas que já estão no meu Wealthbox?

O Pro atualiza contactos que o plugin já criou ou atualizou. A correspondência com contactos que já estavam no Wealthbox antes da instalação chega numa atualização.

Envia as entradas antigas dos formulários?

Não. Só são enviadas as submissões feitas depois de publicar uma associação.

Onde ficam os meus dados?

Na sua própria base de dados WordPress e no Wealthbox. Nada passa pelos meus servidores. O Pro guarda os registos na sua base de dados e usa impressões, não emails em claro, para a correspondência.

Quantos sites cobre uma licença Pro?

Um site por licença. Compre uma para cada site onde usar o Pro.

Este plugin é feito pelo Wealthbox?

Não. É um plugin independente criado por Samama Tahir. Não é feito nem apoiado pelo Wealthbox.

O seu próximo contacto não deve ficar à espera numa caixa de email

Instale o plugin grátis em minutos. Passe para o Pro quando os seus formulários crescerem. Precisa de uma integração à medida para a sua empresa? Também as faço.
