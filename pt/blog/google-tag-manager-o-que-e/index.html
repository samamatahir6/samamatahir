Google Tag Manager: o que é e como funciona

Para que serve o Google Tag Manager, como funciona por dentro e porque facilita tanto a vida a quem anuncia e mede resultados.

Por Samama Tahir · 14 de outubro de 2026 · 5 min de leitura

O Google Tag Manager (GTM) é uma ferramenta gratuita do Google que permite gerir todos os códigos de medição de um site num só sítio, sem mexer no código do site a cada alteração. Em vez de pedir a um programador que cole o código do Google Analytics, depois o do Google Ads, depois o pixel da Meta, instala o Tag Manager uma vez e gere tudo a partir dele. É a base de quase todas as configurações que faço no meu serviço de configuração do GA4 e Google Tag Manager.

Para que serve o Google Tag Manager

Sites modernos têm vários "tags": pequenos pedaços de código que enviam dados para ferramentas externas. O GA4 mede visitas e eventos, o Google Ads mede conversões, a Meta mede o que acontece depois de um anúncio no Instagram, o Microsoft Clarity grava mapas de calor. Sem o GTM, cada um destes códigos é colado à mão no site, e cada mudança obriga a editar o tema.

Com o GTM:

  • Acrescenta, altera ou remove tags sem tocar no código do site.
  • Decide exatamente quando cada tag dispara: em todas as páginas, só na página de agradecimento, só depois de o visitante aceitar cookies.
  • Testa tudo em modo de pré-visualização antes de publicar.
  • Tem um histórico de versões e pode voltar atrás se algo correr mal.

Google Tag Manager e Google Analytics: qual é a diferença?

É a confusão mais comum. O Google Analytics (GA4) é onde os dados são guardados e analisados: relatórios de visitas, origem do tráfego, conversões. O Google Tag Manager é só o mecanismo de entrega: é o que envia os dados do site para o GA4 e para as outras ferramentas. O GTM não mostra relatórios. Pode usar o GA4 sem o GTM, mas o GTM torna a configuração mais flexível e organizada.

Os três conceitos: etiquetas, acionadores e variáveis

Etiquetas (tags)

São o que é enviado. Por exemplo, a etiqueta da Google (que liga o site ao GA4), um evento GA4 chamado generate_lead, uma conversão do Google Ads ou o pixel da Meta.

Acionadores (triggers)

Decidem quando a etiqueta dispara. "Todas as páginas", "clique num link que começa por tel:", "envio de formulário", "visualização da página /obrigado/" ou um evento personalizado enviado pelo site.

Variáveis

São valores que as etiquetas e os acionadores usam: o endereço da página, o texto de um botão clicado, o valor de uma encomenda, o ID de medição do GA4. Em vez de escrever o ID em dez sítios, cria uma variável e usa-a em todo o lado.

A camada de dados (dataLayer)

Para medições mais ricas, como o valor de uma compra ou o produto adicionado ao carrinho, o site envia informação para uma estrutura chamada dataLayer. O GTM lê essa informação e passa-a às etiquetas. A Shopify e muitos plugins de WooCommerce já enviam eventos de e-commerce; em sites à medida, programo o envio. É esta ligação que permite ver no GA4 de onde vêm as vendas.

Como instalar o Google Tag Manager

  1. Crie uma conta e um contentor em tagmanager.google.com, com o endereço do site.
  2. Copie os dois blocos de código que o GTM dá: um vai no <head>, o outro logo após a abertura do <body>.
  3. Em WordPress, pode colocá-los no tema ou com um plugin leve. Na Shopify, o caminho recomendado hoje para o checkout é o dos pixels personalizados, e o tema recebe o código normal.
  4. Crie a etiqueta da Google com o seu ID de medição do GA4, a disparar em todas as páginas.
  5. Abra o modo de pré-visualização, navegue no site e confirme que as etiquetas disparam.
  6. Publique uma versão com um nome claro, por exemplo "GA4 base".

Consentimento de cookies e consent mode

Na União Europeia, ferramentas de medição e publicidade só devem guardar cookies depois de o visitante aceitar. O Google Consent Mode liga o banner de cookies ao Tag Manager: se o visitante recusa, as etiquetas da Google não guardam cookies; se aceita, funcionam normalmente. Desde a versão 2, há também sinais específicos para dados de publicidade. É uma das partes que mais vejo mal feitas, e é importante tanto para o RGPD como para que o Google Ads continue a receber dados.

Erros comuns no Tag Manager

  • Códigos duplicados: o GA4 instalado pelo tema e também pelo GTM, que conta tudo a dobrar.
  • Eventos de compra que disparam ao recarregar a página de confirmação.
  • Etiquetas sem nomes claros, que ninguém sabe para que servem um ano depois.
  • Publicar sem testar em modo de pré-visualização.
  • Ignorar o consentimento, disparando tudo antes de o visitante escolher.
  • Contas em nome de outra pessoa. O contentor deve ser da empresa, com acesso de administrador para si.

Preciso mesmo do Tag Manager?

Para um site pequeno que só usa o GA4 com a medição avançada que já vem incluída, pode não precisar. Assim que quiser medir formulários, chamadas, cliques no WhatsApp, conversões do Google Ads ou o pixel da Meta, o GTM poupa muito tempo e evita erros. Se anuncia no Google, leia também como funciona o Google Ads, porque a medição de conversões é o que separa campanhas que dão retorno das que não dão.

Exemplo: medir o envio de um formulário

Para ver como as peças encaixam, este é o fluxo que uso para medir pedidos de contacto:

  1. O site, depois de o formulário ser enviado com sucesso, envia um evento form_submitted para o dataLayer, com o nome do formulário.
  2. No GTM, crio um acionador de evento personalizado para form_submitted.
  3. Crio uma etiqueta de evento GA4 chamada generate_lead, que dispara com esse acionador e envia o nome do formulário como parâmetro.
  4. Se a empresa anuncia, crio também a etiqueta de conversão do Google Ads com o mesmo acionador.
  5. Testo em modo de pré-visualização e no DebugView do GA4, e só depois publico.

Assim, cada contacto é contado uma vez, no momento certo, em todas as ferramentas.

Perguntas Frequentes

Perguntas frequentes

O que é o Google Tag Manager?

É uma ferramenta gratuita do Google para gerir os códigos de medição e publicidade de um site num só sítio, sem editar o código do site a cada alteração.

O Google Tag Manager substitui o Google Analytics?

Não. O GA4 guarda e mostra os dados; o Tag Manager é só o que envia esses dados do site para o GA4 e para outras ferramentas.

O Google Tag Manager é gratuito?

Sim, a versão normal é gratuita e chega para a grande maioria dos sites.

O Tag Manager torna o site mais lento?

O contentor em si é leve. O que pesa são as etiquetas que coloca lá dentro, por isso convém ter só as necessárias e carregá-las depois do consentimento.
