Plataformas como o WordPress e a Shopify cobrem muito. Estes são os trabalhos que não cobrem.

Porquê Freelance

Desenvolvimento de software à medida, sem uma empresa inteira pelo meio

Uma empresa de desenvolvimento de software põe muitas vezes um gestor de projeto, um designer e dois programadores numa aplicação. Para muitos projetos é mais gente do que o trabalho precisa. Comigo, o programador com quem fala é quem escreve o código, e as decisões levam uma conversa em vez de três reuniões.

Se o trabalho for mais simples do que uma aplicação à medida, digo-lhe. Às vezes a resposta certa é um plugin WordPress ou uma app Shopify, e isso sai mais barato.

Para Quem

Desenvolvimento de aplicações web para empresas em Portugal e lá fora

Quando é útil, reúno-me presencialmente com empresas do Porto, de Vila Nova de Gaia e arredores. Com empresas no resto do país, no Reino Unido e nos Estados Unidos, o trabalho é feito online, em português ou em inglês.

Tecnologia

Com que tecnologias desenvolvo aplicações web

No frontend uso sobretudo React, e Vue quando o projeto já está nessa tecnologia. No backend trabalho com Laravel, CodeIgniter e Node.js, com bases de dados MySQL ou PostgreSQL, e ligo serviços externos pelas suas APIs: pagamentos, CRMs, ferramentas de contabilidade como o QuickBooks e formulários como o Gravity Forms. Escolho a tecnologia que serve o projeto e quem o vai manter, não a mais recente.

Antes de Começar

O que preciso para orçamentar software à medida

O mais útil que me pode enviar é uma lista das pessoas que vão usar a aplicação e do que cada uma precisa de fazer. Junte as ferramentas com que tem de comunicar e as folhas de cálculo ou tarefas manuais que deve substituir. A partir daí proponho uma primeira versão pequena o suficiente para ser feita depressa e útil o suficiente para aprender com ela.

Perguntas Frequentes

Perguntas sobre software à medida

O que é desenvolvimento de software à medida?

É criar uma aplicação feita para o seu negócio, em vez de adaptar o negócio a um software genérico. Faz sentido quando o processo é específico ou quando precisa de ligar sistemas que não falam entre si.

Como criar uma aplicação web para a minha empresa?

Começa-se por definir o problema que ela resolve e quem a vai usar. Depois desenha-se o mínimo que resolve esse problema, constrói-se por fases e melhora-se com o uso real. Ajudo em todas as fases.

Que tecnologias usa?

Sobretudo React, e Vue quando faz sentido. No backend, PHP com Laravel ou CodeIgniter, ou Node.js com Express, sempre com uma base de dados real.

Quanto custa uma aplicação à medida?

Depende do âmbito. Envio um orçamento fechado por escrito depois de uma chamada gratuita, dividido em fases nas aplicações maiores.

Pode continuar uma aplicação que outro programador começou?

Sim. Posso rever o código primeiro e dizer-lhe honestamente se vale a pena continuar ou se é melhor refazer.

De quem é o código?

É seu. O código fica no seu repositório ou no seu servidor, e recebe tudo o que é preciso para o pôr a funcionar e alterar, comigo ou com outro programador no futuro.

A aplicação pode crescer mais tarde?

Sim, e é assim que costumo trabalhar. Começamos por uma primeira versão com o essencial, vemos como é usada e acrescentamos funcionalidades por ordem de importância. O código é organizado a pensar nisso, para que crescer não obrigue a refazer tudo.

Tem uma aplicação em mente?

Diga-me o que a aplicação tem de fazer. Digo-lhe honestamente se precisa de código à medida ou de uma ferramenta mais simples.
