Web Development Services for Businesses in Porto

I design, build, and maintain WordPress websites, Shopify stores, and custom web applications, so the site behind your business is fast, secure, and actually easy to keep running.

WordPress Development

Custom WordPress builds and theme customization, not a stack of plugins bolted together. I work across Elementor, Divi, Bricks, WPBakery, and Oxygen depending on what a project actually needs, plus fully custom themes when it doesn't fit a builder.

  • Custom themes, and theme customization on Elementor, Divi, Bricks, WPBakery, and Oxygen
  • Advanced Custom Fields, Custom Post Types, and Gutenberg blocks
  • WooCommerce, Gravity Forms, JetEngine, and Crocoblock builds
  • Performance optimization, security hardening, and plugin/theme cleanup

A WordPress site that stays fast and secure as it grows, not one that slows down with every new plugin.

Shopify Development

Shopify store builds and theme customization in Liquid, including the Dawn theme, with the app integrations a growing store actually relies on.

  • Theme customization in Liquid, including the Dawn theme
  • Storefront API and Admin API work for custom functionality
  • App integrations, including Appstle and Recharge for subscriptions
  • Store customization built around how customers actually shop

Custom Web Applications

When a business needs something beyond WordPress or Shopify, I build it directly: React or Vue on the frontend, PHP (Laravel, CodeIgniter) or Node.js/Express on the backend, backed by a real database.

  • React and Vue.js frontends, built responsive from the start
  • Laravel, CodeIgniter, and Node.js/Express backends
  • MySQL, MongoDB, and PostgreSQL for database-driven applications
  • REST APIs, JWT and OAuth authentication, and webhooks for third-party integrations

Built to fit how the business actually works, not forced into a template it doesn't need.

E-Commerce

Online stores on WooCommerce or Shopify, built around a checkout that actually converts: clear payment flows, working subscription systems, and product setups that don't fight the platform.

  • WooCommerce and Shopify store builds and customization
  • Payment integrations and checkout workflows
  • Subscription systems, including Recharge and Appstle
  • Product and store customization aimed at conversion, not just appearance
