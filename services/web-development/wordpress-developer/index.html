What I Do

WordPress development, from themes to plugins

Four kinds of WordPress work make up most of my projects.

Custom themes and builder sites

A custom theme when the design needs it, or a clean build in Elementor, Divi, Bricks, WPBakery or Oxygen when the team wants to edit pages visually.

Custom plugins and integrations

When no plugin does what the business needs, I write one. I built a plugin that sends Gravity Forms submissions to two CRMs, Advyzon and Wealthbox, after no existing integration could.

Speed and fixes

Slow pages, plugin conflicts, broken layouts after an update, a site someone else built and nobody can maintain. I find the cause and fix it, instead of adding another plugin.

WordPress SEO and maintenance

Clean structure, fast pages and structured data from the start, then updates, backups and small changes so the site stays secure and current.

Why Freelance

A WordPress developer, not a stack of plugins

A lot of slow WordPress sites are slow for the same reason: a plugin for every feature, a builder on top of a theme on top of another builder. I keep sites lean. If a feature takes twenty lines of code, it gets twenty lines of code, not another plugin to update forever.

As a WordPress SEO consultant as well as a developer, I build pages that search engines can read properly from day one. If you are comparing freelancers and want to know how I work before hiring, read hire a WordPress developer.

I work online with businesses in the UK and the US, with the same working hours as the UK and a daily overlap with the US East Coast. Businesses in Porto, Vila Nova de Gaia and nearby can also meet me in person when it helps.

Common Jobs

WordPress problems I am often asked to fix

A lot of my WordPress work starts with a site that already exists. It loads slowly because of a heavy page builder and too many plugins. An update broke the layout. A form stopped sending emails. A plugin that did one small job has turned into a security risk. Someone needs WooCommerce to do something it doesn't do out of the box.

In each case I look at the cause before touching anything, keep a backup, and work on a copy when the change is risky. When a small custom plugin is cleaner than three off-the-shelf ones, I write it. One example is a custom plugin I built that connects Gravity Forms to Advyzon and Wealthbox for a financial advisory business.

I also wrote a tutorial on a mobile-friendly multi-level WordPress menu.

FAQ

WordPress questions

What does a WordPress developer do?

A WordPress developer builds and maintains WordPress sites: themes, plugins, page builder layouts, WooCommerce stores, and the fixes and speed work when something goes wrong. A good one also knows when a feature needs code and when an existing plugin is the better answer.

Can you fix a WordPress site someone else built?

Yes. A lot of my work is on sites I did not build: slow pages, conflicts after updates, broken forms and layouts, or a builder setup nobody can edit any more.

Do you offer WordPress maintenance?

Yes. Updates, backups, security checks and small content or layout changes, so the site stays secure and current without you having to think about it.

Should I use WordPress or Shopify?

WordPress suits content-led sites and businesses that want to edit their own pages. Shopify is usually simpler for a store. I build on both and will recommend the one that fits.

How much does a WordPress developer cost?

It depends on the work: a fix, a builder site and a custom theme with a plugin are very different jobs. After a free call I send a written fixed quote.

Can you move my site to WordPress from another platform?

Yes. I move the content, keep the URLs or redirect them properly so you don't lose search traffic, and rebuild the design in WordPress. I check the redirects in Search Console after launch.

Need a WordPress developer?

Tell me about the site and what it needs. I will tell you honestly whether it is a quick fix or a bigger job.
